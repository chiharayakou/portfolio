Architecture & stack
--------------------
- Static site for GitHub Pages
- HTML + custom CSS (no Bootstrap or other UI frameworks)
- Vanilla JavaScript
- Multilingual support planned (Russian default)
- Colour system extracted from a dark-themed reference UI

Key technical decisions
-----------------------
- Pure custom CSS instead of Bootstrap for a distinctive professional look
- CSS split into three files: variables.css, base.css, layout.css
- Design tokens stored as CSS custom properties
- Mobile-first responsive approach using modern CSS (min(), logical properties)
- Footer made to stick to the bottom of the viewport with flexbox
- Year in the footer is updated automatically via JavaScript

Hosting & constraints
---------------------
- Hosting: GitHub Pages (free)
- Repository must remain public
- No server-side code (static only)
