Key technical decisions
-----------------------
- Pure custom CSS instead of Bootstrap for a distinctive look
- CSS split into variables.css, base.css, layout.css
- Design tokens as CSS custom properties
- Mobile-first responsive grid using modern CSS (minmax, aspect-ratio, logical properties)
- Footer sticks to the bottom of the viewport with flexbox
- Project cards generated from JSON
- Status system: live / offline / development (with colour tokens)
- Optional github and url fields on projects
- Images with consistent aspect-ratio and object-fit: cover
